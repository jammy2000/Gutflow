# 웰빙내과 수액실 — 인계

## 처음 판 (2026-11-17, v0.1)

**무엇을:** 수액 치료 과정 프로그램. 문진표는 다른 세션(상담앱)에서 만들고, 여기는 **문진 뒤 실제 치료 과정**만 다룬다.
프로그램 선택 → 회차마다 오늘 확인 → 조제 → 주입 속도 → 반응 기록 → EMR 글 → 경구 보충제로 이어가기.

**왜 따로 폴더인가:** 상담앱 저장소(`rexzerg/wellbeing-apps`)는 이 세션에서 접근 허가가 나지 않았다.
상담앱과 같은 방식(파이썬 표준 라이브러리 + SQLite + `index.html` 한 장)으로 만들어 두었으니,
나중에 `wellbeing-apps/iv-app/`로 그대로 옮기거나 상담앱 탭으로 합치면 된다. (아래 「옮기는 법」)

**시험:** `cd wellbeing-iv/tests && python -m unittest discover` → 50개 통과 (v0.2).
Playwright 1440·1920 화면 캡처로 확인했고, JS 오류는 없었다.

## v0.4 (2026-11-21) — 백 나누는 법 바꾸고 같은 조합 합쳐 6종

부원장님 규칙:
- **기본** = N/S 100 한 백에 삐콤헥사 + 마시주 5mL (+ 처방별 약)
- **프리미엄** = 기본과 같은 N/S 백 + **써프라민 100 단독** 한 백
- N/S에 삐콤·C·Mg 같이 가능, 삐콤·비치라이트·Mg 같이 가능
- **비치라이트 × 메리트씨는 금지** → 비치라이트가 있으면 비타민C는 N/S 100에 따로

| 처방 (합친 것) | 기본 | 프리미엄 | 일정 |
|---|---|---|---|
| 면역증강 · 갱년기 | N/S + 삐콤 + 마시주 + 메리트씨 (5만) | + 써프라민 단독 (8만) | 3주 6회 / 2주 4회 / 1회 |
| 피로회복 · 감기몸살 | N/S + 삐콤 + 마시주 + 메리트씨 + 푸르설타민 (5만) | + 써프라민 단독 (8만) | 2주 4회 / 4주 8회 / 1회 |
| 활력 · 숙취회복 | ① N/S + 삐콤 + 마시주 + 비치라이트 + 푸르설타민 ② N/S + 메리트씨 (6만) | + 써프라민 단독 (9만) | 2주 4회 / 1회 |
| 백옥 · 간기능개선 | N/S + 삐콤 + 마시주 + 비치라이트 1V (5만) | 비치라이트 2V + 써프라민 단독 (9만) | 5주 10회 / 2주 4회 / 1회 |
| 어지러움 (혈류개선) | ① N/S + 삐콤 + 마시주 + 라노빈 ② N/S + 진코발 (5만) | + 써프라민 단독 (8만) | 1회 / 2주 4회 |
| 장염 | N/S + 삐콤 + 마시주 (3.5만) / 플러스 + 메리트씨 (6만) | + 써프라민 단독 (9만) | 1회 |

- 장염 플러스·프리미엄은 면역증강·갱년기 기본·프리미엄과 조합이 같다. 그래도 원장님 확정 가격과 홍보영상이 따로 있어 남겼다.
- 라노빈은 메리트씨·비치라이트·써프라민과 같은 백 금지라서, 어지러움(C·글루타치온 없음) N/S 백에만 넣었다. 피로·활력 프리미엄의 따로 라노빈 백은 뺐다.
- 섞기 규칙: 「비치라이트 × 삐콤」 금지를 없앴다. 「마시주 × 비치라이트」는 「주의」(같은 백 가능, 섞은 뒤 바로)로 바꿨다.
- 옛 프로그램 이름(meno·cold·hangover·liver)으로 이미 시작한 코스는 합친 프로그램 구성으로 열린다. 새로 고를 때는 안 보인다.
- 문서: `웰빙내과_맞춤영양수액_구성표.docx` (7쪽). 시험 58개 통과.

## v0.3 (2026-11-20) — 맞춤 영양수액 10종 (v0.4에서 6종으로 합침)

부원장님이 다니는 병원의 「맞춤형 영양주사 9종 구성표」처럼, 웰빙내과에서 당장 할 수 있는 10종으로 다시 짰다.

- **기본** = N/S 100mL + 삐콤헥사 1A + 마시주 5mL(0.5g)
- **프리미엄** = 써프라민 100mL + 삐콤헥사 1A + 마시주 5mL
- 붙이는 것: 피로 계열 → 메리트씨 1V(20mL=10g), 백옥·숙취·간 → 비치라이트(따로 백), 어지러움 → 진코발(따로 백)
- 라이넥은 아직 조합하지 않음. 장면역강화(디펩티벤)는 「준비 중」으로 보관(`PROGRAMS_LATER`). 입고 뒤 `PROGRAM_ORDER`로 옮기면 켜진다.

| 처방명 | 붙이는 것 | 기본 / 프리미엄 (1회 제안가) | 일정 |
|---|---|---|---|
| 면역증강 | 비타민C | 5만 / 8만 | 3주 6회 |
| 활력(기력증진) | 비타민C + 글루타치온(따로) | 6만 / 9만 | 2주 4회 |
| 피로회복 | 비타민C | 5만 / 8만 | 2주 4회 |
| 어지러움(혈류개선) | 진코발(따로) | 5만 / 8만 | 1회 |
| 갱년기 | 비타민C (라이넥은 입고 뒤) | 5만 / 8만 | 2주 4회 |
| 백옥(피부미백) | 글루타치온 600(기본)·1200(프리미엄), 따로 | 5만 / 9만 | 5주 10회 |
| 숙취회복 | 비타민C + 글루타치온(따로) | 6만 / 9만 | 1회 |
| 간기능개선 | 글루타치온(따로) | 6만 / 9만 | 2주 4회 |
| 장염 | 플러스에 비타민C | 3.5만 / 6만 / 9만 (원장님 확정) | 1회 |
| 감기몸살 | 비타민C | 5만 / 8만 | 1회 |

- **11-20 추가: 라노빈(B12)·푸르설타민(마늘주사)**
  - 푸르설타민 1A → 피로회복·활력·숙취회복·감기몸살 기본 백에 넣음(비타민C·마그네슘·삐콤과 같은 백 가능, 천천히).
  - 라노빈 1A → 어지러움 기본 백(비타민C 없음). 메리트씨·비치라이트·써프라민과는 같은 백 금지라서, 어지러움·피로회복·활력 프리미엄에서는 N/S 100 + 라노빈을 따로 연결.
  - 오늘 확인에 「마늘주사 뒤 불편·쇼크 경험」 → 푸르설타민 빼기. 섞기 주의에 「써프라민 × 푸르설타민」(아황산이 B1 분해 → 섞은 뒤 바로).
- 섞기 규칙 바뀐 점: **마시주 × 메리트씨**를 「같은 백 금지」에서 **「주의」(같은 백 가능, 섞은 뒤 바로, 뿌옇면 버리기)**로 낮췄다. 메리트씨의 탄산수소나트륨은 산도를 맞추는 데 쓰여 대부분 없어지기 때문이다. 마시주 × 비치라이트는 그대로 「같은 백 금지」다.
- 문서: `웰빙내과_맞춤영양수액_10종_구성표.docx`. 한눈에 보는 10종, 개별 구성, 같이 섞으면 안 되는 조합, 맞기 전 확인을 담았다. 프로그램 자료를 바꾸면 `python tools/구성표_만들기.py`로 다시 만든다(node + docx 필요).
- 시험: 53개 통과.

## v0.2 (2026-11-17 오후) — 원내 수액 재고로 다시 짬

**재고(EMR 수액 목록):** 써프라민 7.5% 100mL · N/S 100mL · 삐콤헥사 · 메리트씨 · 마시주 10% · 라노빈 · 진코발 · 비치라이트
+ 디펩티벤(장면역강화) · 라이넥(입고 예정). **히시파겐C는 허가 취하로 뺐다.**

| 원내 이름 | 성분 (식약처 허가정보) |
|---|---|
| 써프라민 100mL | 아미노산 7.5% — 간장애 뇌증용 BCAA 고함량. 아황산·시스테인 함유. 100mL당 36분 이상 |
| 메리트씨 | 아스코르브산 500mg/mL → 10mL=5g, 20mL=10g. 냉장·차광. 탄산수소나트륨 함유 |
| 마시주 10% | 황산마그네슘 → 10mL=1g. 1g당 30분 이상 |
| 삐콤헥사 2mL | B1·B2·B6·B12(10µg)·니코틴아미드·판테놀. 아황산 함유, 차광 |
| 라노빈 2mL | 히드록소코발라민(B12) 5mg |
| 진코발 5mL | 은행엽엑스 17.5mg. 희석·배합 정보 없음 → 단독 |
| 비치라이트 | 글루타치온 600mg 가루. 탄산수소나트륨 함유. 1200mg = 2V |
| 디펩티벤 | 알라닐-글루타민 20%. **아미노산 수액에만**, 1:5 이상 → 써프라민 100mL에 20mL까지 |
| 라이넥 2mL | 태반 — 허가 용법 피하·근육 → 「따로 주사」로 둠 (설정에서 백에 옮길 수 있음) |

### 같이 섞으면 안 되는 조합 (화면 오른쪽 칸에 항상 표시)

| 조합 | 등급 | 이유 |
|---|---|---|
| 메리트씨 × 라노빈 | 같은 백 금지 | 비타민C가 B12 분해 |
| 비치라이트 × 라노빈 | 같은 백 금지 | 글루타치온이 B12와 바로 결합 |
| 써프라민 × 라노빈 | 같은 백 금지 | 시스테인·아황산 반응(추정) |
| 마시주 × 메리트씨·비치라이트 | 같은 백 금지 | 두 약의 탄산수소나트륨 — 마시주 허가사항 「혼합 피함」 |
| 디펩티벤 × 다른 모든 약 | 같은 백 금지 | 허가사항: 희석액에 다른 약 넣지 않음 |
| 진코발 × 다른 모든 약 | 같은 백 금지 | 배합 자료 없음 → 단독 |
| 비치라이트 × 메리트씨·삐콤헥사·써프라민 | 같은 백 금지 | 자료 없음 → 보수적으로 분리 |
| 메리트씨 × 삐콤헥사 | 주의 | 같은 백 가능 — 섞은 뒤 바로, 차광 |
| 써프라민 × 삐콤헥사 | 주의 | 아황산이 B1 분해 — 미리 섞어 두지 않기 |

- 처음 조제 24개(8개 프로그램 × 3등급)는 이 규칙을 모두 피한다. 시험으로 확인한다.
- 「설정」에서 금지 조합을 만들면 빨간 표시와 함께 몇 번 백인지 알려 준다.
- 기본 백 모양:
  - ① 마그네슘·B 백: N/S + 마시주 + 삐콤헥사 + 라노빈
  - ② 비타민C 백: N/S + 메리트씨
  - ③ 백옥 백: N/S + 비치라이트
  - ④ 아미노산 백: 써프라민 + 삐콤헥사
  - ⑤ 디펩티벤 백: 써프라민 + 디펩티벤
  - ⑥ 진코발 백: N/S + 진코발
- 백마다 권장 시간을 화면에 보여 준다. 다음 백은 앞 백이 끝나면 식염수를 흘린 뒤 연결한다.

### 오늘 확인에 더한 것
- 아황산 과민·천식 → 써프라민 백·삐콤헥사 뺌
- 항응고·항혈소판제·수술 예정 → 진코발 뺌
- 임신 → 진코발·디펩티벤 뺌 + 멈춤
- 콩팥 기능 저하 → 써프라민 백 전체 + 마시주·메리트씨·디펩티벤 뺌
- 심한 간질환 → 디펩티벤 뺌

| 스트레스 | 2주 4회 (또는 주1회 4회, 1회) | 45,000 / 65,000 / 90,000 | MC2, +마늘, ORANGE |
| 환절기 면역강화 | 3주 6회 | 50,000 / 70,000 / 100,000 | MC4, +아연, ORANGE+아연 |
| 장면역강화(과민성장) | 디펩티벤 4주 4회 + 경구 12주 | 50,000 / 70,000 / 100,000 | 디펩티벤 50·100mL |

- 장염을 뺀 가격은 다른 의원 조사 범위 안에서 잡은 **제안가**다. 「설정」에서 바꾼다.
- 회차권 값은 1회 값 × 회수 × (1 − 할인 10%)로 계산하고, 코스를 시작할 때 고칠 수 있다.

### 장면역강화 (IBS)
- **유형별 보충제(로마 IV):** 설사형은 보울라디 유산균, 변비형은 비피더스 유산균 + 차전자피, 혼합형은 복합 유산균 + 차전자피(소량).
- 모든 유형에 공통으로 **L-글루타민 분말 15g/일, 12주**를 넣었다. 수액 디펩티벤을 먹는 글루타민으로 이어가는 구조다.
- 주된 불편에 따라 더한다: 복통·팽만은 페퍼민트 오일, 스트레스는 테아닌, 비타민D 낮음은 비타민D.
- 처방약은 빠른 단추로 고른다: 트리메부틴, 라모세트론, 리나클로타이드 등.
- **IBS-SSS(0~500)**를 0·4·8·12주에 잰다. 「오늘」 화면에 재야 할 날이 뜬다.
- 디펩티벤 규칙 두 가지를 자동으로 검사한다:
  - 바탕액은 디펩티벤 양의 5배 이상이어야 한다.
  - 하루 2.5 mL/kg을 넘지 않아야 한다. 몸무게를 넣으면 검사한다.

### 경구 보충제로 이어가기 (모든 프로그램)
- 프로그램마다 **수액과 함께**(회차 사이) / **수액 뒤 유지**(4~12주) 목록이 있다.
- 「지급」을 누르면 다음 구매일(1통 일수 기준)이 계산되고, 「오늘」 화면의 **보충제 다 떨어질 때** 목록에 올라온다.
- 수액 회차를 다 맞으면 코스 상태가 자동으로 **수액중 → 경구유지**로 바뀐다.
- 보충제 1통 값은 비워 두었다. 「설정 → 보충제 값」에서 원장님이 넣는다.

## 회차 진행 화면이 자동으로 하는 일

| 오늘 확인 | 자동 처리 |
|---|---|
| 수축기 ≤ 100 | **메가네슘 빼기** (원내 규칙) |
| 수축기 < 90 또는 ≥ 180 | 멈춤 → 원장님 확인 체크 후 진행 |
| 임신·수유, 주사 뒤 쇼크 경험 | 멈춤 → 원장님 확인 체크 후 진행 |
| 콩팥 기능 저하·투석 | 마그네슘·고용량 비타민C·디펩티벤·아미노산 빼기 |
| G6PD 결핍·콩팥돌·통풍 | 메가그린(비타민C 10g) 빼기 |
| 당뇨 | D/W → N/S로 바꾸기, 손끝 혈당 위양성·알파리포산 저혈당 안내 |
| 방실차단·근무력증·디곡신 | 마그네슘 빼기 |
| 혈압 조절 안 됨·저칼륨 | 감초(히시파겐) 빼기 |
| 심한 간질환 | 디펩티벤·아미노산 빼기 |
| 마늘주사 뒤 불편 | 푸르설타민 빼기 |
| 1년 안 헌혈 계획 | 라이넥 빼기 |
| 처음 맞음·75세 이상, 심부전 | 주입 시간 1.5배 |

- 조제 카드에서 성분마다 체크(섞었는지)할 수 있다. 성분 메모(예: 「타치온은 녹인 뒤 바로」)와 환자에게 미리 말할 것(예: 마늘 냄새, 열감)이 함께 뜬다.
- 주입 속도는 총량과 시간으로 계산하고, 수액 세트 15·20·60 gtt/mL에 맞춰 분당 방울 수를 보여 준다. 시작·끝 단추를 누르면 시각이 찍힌다.
- 저장하면 EMR 글(한 줄 45바이트)이 나오고, 다음 권장일과 환자 안내문 인쇄가 이어진다.
- 환자 안내문에는 **수액 성분명을 넣지 않는다.** 들어가는 것은 회차, 다음 날짜, 생활 안내, 보충제 먹는 법뿐이다.

## 원장님이 정할 것

1. 장염을 뺀 7개 프로그램의 판매가와 보충제 1통 값 (「설정」)
2. 각 등급 조제: 이 초안은 원내 조제표 MC·PNT·색 프로그램을 바탕으로 짰다. 「설정」에서 성분과 양을 바꿀 수 있다.
3. **급여 등재 약의 비급여 사용:** 라노빈·삐콤헥사·마시주·디펩티벤은 급여 등재 약이다(라노빈은 2026-08 등재). EMR에서 비급여로 받는 방식이 맞는지 심평원(1644-2000)에 확인해야 한다. 신사업 세션의 같은 질문과 함께 물으면 된다.
4. **디펩티벤 병 낭비:** 50mL 병에서 20mL만 쓰면 나머지는 버린다(섞은 뒤 바로 사용). 장면역 프리미엄(2백 40mL)이나 한 병을 두 환자에게 나눠 쓰는 방식은 원장님이 판단한다.
5. **써프라민:** 허가 효능은 「간장애 뇌증 개선」(BCAA 고함량)이다. 일반 영양 아미노산 수액으로 바꿀지 원장님이 정한다.
6. **라이넥:** 기본은 「따로 주사(피하·근육)」다. 수액에 섞으려면 「설정」에서 백을 바꾼다.

## 파일

- `catalog.py`: 처음 값. 프로그램·등급·조제·보충제·확인 항목. 제품 성분은 식약처 의약품안전나라로 확인했다(11-17).
- `engine.py`: 계산(조제 목록, 주입 속도, 일정, 보충제 계획, IBS-SSS, EMR 글). DB를 쓰지 않는다.
- `server.py`: API와 SQLite.
  - 표: `patients`, `iv_courses`, `iv_sessions`, `iv_scores`, `iv_oral`, `iv_settings`
- `index.html`: 화면 한 장. 탭은 오늘 / 환자 / 프로그램표 / 설정.
- `tests/test_iv.py`: 시험.

## 옮기는 법 (상담앱 저장소로)

1. 저장소 접근 허가가 나면 이 폴더를 `wellbeing-apps/iv-app/`으로 복사한다. 그러면 상담앱·환자앱 옆의 세 번째 앱이 된다.
2. 상담앱에 합칠 때:
   - `patients` 표는 상담앱 것을 쓴다(차트번호가 같다).
   - `iv_*` 표 5개는 그대로 쓴다.
   - `programs_v1.json`의 `courses:[{key:"iv"}]` 회차 기록은 `iv_sessions`로 대신한다.
3. 환자앱에는 「수액 n/N회」와 다음 날짜만 보낸다(성분명 금지 규칙과 같다).
