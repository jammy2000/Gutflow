# 웰빙내과 수액실 — 인계

## 현재 판 (2026-11-17, v0.1)

**무엇을:** 수액 치료 과정 프로그램. 문진표는 다른 세션(상담앱)에서 만들고, 여기는 **문진 뒤 실제 치료 과정**만 다룬다.
프로그램 선택 → 회차마다 오늘 확인 → 조제 → 주입 속도 → 반응 기록 → EMR 글 → 경구 보충제로 이어가기.

**왜 따로 폴더인가:** 상담앱 저장소(`rexzerg/wellbeing-apps`)는 이 세션에서 접근 허가가 나지 않았다.
상담앱과 같은 방식(파이썬 표준 라이브러리 + SQLite + `index.html` 한 장)으로 만들어 두었으니,
나중에 `wellbeing-apps/iv-app/`로 그대로 옮기거나 상담앱 탭으로 합치면 된다. (아래 「옮기는 법」)

**시험:** `cd wellbeing-iv/tests && python -m unittest discover` → 35개 통과.
Playwright 1440·1920 화면 캡처로 확인했고, JS 오류는 없었다.

## 프로그램 8종

| 프로그램 | 일정(기본) | 기본 / 플러스 / 프리미엄 (1회) | 바탕이 된 원내 조제 |
|---|---|---|---|
| 장염 | 1회 | 35,000 / 60,000 / 90,000 **(원장님 확정)** | MC3, +디펩티벤, +NT2 |
| 감기몸살 | 1회 | 40,000 / 60,000 / 90,000 | MC1, MC4, +BLUE |
| 만성피로 | 2주 4회 (또는 4주 8회) | 50,000 / 70,000 / 100,000 | MC2, +마늘, +태반·백옥 |
| 항노화 | 4주 4회 주1회 (또는 4주 8회 주2회) | 60,000 / 90,000 / 130,000 | MC6, +백옥, PINK+신데렐라 |
| 피부미백(백옥) | 5주 10회 주2회 (또는 4주 8회) | 40,000 / 60,000 / 90,000 | 백옥600, C+백옥1200, PNT2 |
| 스트레스 | 2주 4회 (또는 주1회 4회, 1회) | 45,000 / 65,000 / 90,000 | MC2, +마늘, ORANGE |
| 환절기 면역강화 | 3주 6회 | 50,000 / 70,000 / 100,000 | MC4, +아연, ORANGE+아연 |
| 장면역강화(과민성장) | 디펩티벤 4주 4회 + 경구 12주 | 50,000 / 70,000 / 100,000 | 디펩티벤 50·100mL |

- 장염을 뺀 가격은 다른 의원 조사 범위 안에서 잡은 **제안가**다. 「설정」에서 바꾼다.
- 회차권 값은 1회 값 × 회수 × (1 − 할인 10%)로 계산하고, 코스를 시작할 때 고칠 수 있다.

### 장면역강화 (IBS)
- **유형별 보충제(로마 IV):** 설사형은 보울라디 유산균, 변비형은 비피더스 유산균 + 차전자피, 혼합형은 복합 유산균 + 차전자피(소량).
- 모든 유형에 공통으로 **L-글루타민 분말 15g/일, 12주**를 넣었다. 수액 디펩티벤을 먹는 글루타민으로 이어가는 구조다.
- 주된 불편에 따라 더한다: 복통·팽만은 페퍼민트 오일, 스트레스는 테아닌, 비타민D 낮음은 비타민D.
- 처방약은 빠른 단추로 고른다: 트리메부틴, 라모세트론, 리나클로타이드 등.
- **IBS-SSS(0~500)**를 0·4·8·12주에 잰다. 「오늘」 화면에 재야 할 날이 뜬다.
- 디펩티벤 규칙 두 가지를 자동으로 검사한다:
  - 바탕액은 디펩티벤 양의 5배 이상이어야 한다.
  - 하루 2.5 mL/kg을 넘지 않아야 한다. 몸무게를 넣으면 검사한다.

### 경구 보충제로 이어가기 (모든 프로그램)
- 프로그램마다 **수액과 함께**(회차 사이) / **수액 뒤 유지**(4~12주) 목록이 있다.
- 「지급」을 누르면 다음 구매일(1통 일수 기준)이 계산되고, 「오늘」 화면의 **보충제 다 떨어질 때** 목록에 올라온다.
- 수액 회차를 다 맞으면 코스 상태가 자동으로 **수액중 → 경구유지**로 바뀐다.
- 보충제 1통 값은 비워 두었다. 「설정 → 보충제 값」에서 원장님이 넣는다.

## 회차 진행 화면이 자동으로 하는 일

| 오늘 확인 | 자동 처리 |
|---|---|
| 수축기 ≤ 100 | **메가네슘 빼기** (원내 규칙) |
| 수축기 < 90 또는 ≥ 180 | 멈춤 → 원장님 확인 체크 후 진행 |
| 임신·수유, 주사 뒤 쇼크 경험 | 멈춤 → 원장님 확인 체크 후 진행 |
| 콩팥 기능 저하·투석 | 마그네슘·고용량 비타민C·디펩티벤·아미노산 빼기 |
| G6PD 결핍·콩팥돌·통풍 | 메가그린(비타민C 10g) 빼기 |
| 당뇨 | D/W → N/S로 바꾸기, 손끝 혈당 위양성·알파리포산 저혈당 안내 |
| 방실차단·근무력증·디곡신 | 마그네슘 빼기 |
| 혈압 조절 안 됨·저칼륨 | 감초(히시파겐) 빼기 |
| 심한 간질환 | 디펩티벤·아미노산 빼기 |
| 마늘주사 뒤 불편 | 푸르설타민 빼기 |
| 1년 안 헌혈 계획 | 라이넥 빼기 |
| 처음 맞음·75세 이상, 심부전 | 주입 시간 1.5배 |

- 조제 카드에서 성분마다 체크(섞었는지)할 수 있다. 성분 메모(예: 「타치온은 녹인 뒤 바로」)와 환자에게 미리 말할 것(예: 마늘 냄새, 열감)이 함께 뜬다.
- 주입 속도는 총량과 시간으로 계산하고, 수액 세트 15·20·60 gtt/mL에 맞춰 분당 방울 수를 보여 준다. 시작·끝 단추를 누르면 시각이 찍힌다.
- 저장하면 EMR 글(한 줄 45바이트)이 나오고, 다음 권장일과 환자 안내문 인쇄가 이어진다.
- 환자 안내문에는 **수액 성분명을 넣지 않는다.** 들어가는 것은 회차, 다음 날짜, 생활 안내, 보충제 먹는 법뿐이다.

## 원장님이 정할 것

1. 장염을 뺀 7개 프로그램의 판매가와 보충제 1통 값 (「설정」)
2. 각 등급 조제: 이 초안은 원내 조제표 MC·PNT·색 프로그램을 바탕으로 짰다. 「설정」에서 성분과 양을 바꿀 수 있다.
3. **히시파겐C 허가 취하(2026-08-25):** 재고가 떨어지면 글리파겐주 또는 지씨웰빙글리메타주로 바꿔야 한다. 바꿀 때 「설정」의 이름만 바꾸면 된다.
4. 디펩티벤의 비급여 처리: 급여목록 약을 허가 범위 밖 목적으로 쓸 때의 처리를 심평원(1644-2000)에 확인해야 한다. 신사업 세션의 같은 질문(급여목록 약을 피로 목적으로 비급여 사용)과 함께 물으면 된다.
5. 라이넥·멜스몬의 허가 용법은 피하·근육이다. 원내 조제표대로 수액에 섞을지는 원장님 지시를 따른다(성분 메모에 표시해 둠).

## 파일

- `catalog.py`: 처음 값. 프로그램·등급·조제·보충제·확인 항목. 제품 성분은 식약처 의약품안전나라로 확인했다(11-17).
- `engine.py`: 계산(조제 목록, 주입 속도, 일정, 보충제 계획, IBS-SSS, EMR 글). DB를 쓰지 않는다.
- `server.py`: API와 SQLite.
  - 표: `patients`, `iv_courses`, `iv_sessions`, `iv_scores`, `iv_oral`, `iv_settings`
- `index.html`: 화면 한 장. 탭은 오늘 / 환자 / 프로그램표 / 설정.
- `tests/test_iv.py`: 시험.

## 옮기는 법 (상담앱 저장소로)

1. 저장소 접근 허가가 나면 이 폴더를 `wellbeing-apps/iv-app/`으로 복사한다. 그러면 상담앱·환자앱 옆의 세 번째 앱이 된다.
2. 상담앱에 합칠 때:
   - `patients` 표는 상담앱 것을 쓴다(차트번호가 같다).
   - `iv_*` 표 5개는 그대로 쓴다.
   - `programs_v1.json`의 `courses:[{key:"iv"}]` 회차 기록은 `iv_sessions`로 대신한다.
3. 환자앱에는 「수액 n/N회」와 다음 날짜만 보낸다(성분명 금지 규칙과 같다).
