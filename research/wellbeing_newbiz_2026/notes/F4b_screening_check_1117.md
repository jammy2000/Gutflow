# 국가건강검진기관 등록 여부 재확인 (2026-11-17)

## 결론
- **공개 최신 파일(2025-10-31 기준)에 웰빙내과의원은 없다.** 전국 25,589곳 전체에서 "웰빙"이 들어간 기관은 11곳이다. 고양시에는 "웰빙치과의원"(일산동구) 1곳뿐이다. 일반·위암·대장암·간암 어느 유형에도 없다. [근거] data.go.kr 15156506 「국민건강보험공단_검진기관별 검진유형내역_20251031」(등록 2025-12-15, 1회성 데이터, 주소 없음 → 이름 대조).
- 2025.11. 이후 지정 여부는 **확인 못 함**. 실시간 자료는 건보공단 오픈API(data.go.kr 15154419 「검진기관 찾기 조회」, 15154392, 15154423, 수정 2025-12)에 있으나 이용자 서비스키가 필요하다. 건강iN(hi.nhis.or.kr)은 이 환경에서 접속 차단.
- 조회는 의원 이름을 외부 검색창에 넣지 않고, 전체 파일을 내려받아 로컬에서 대조했다.

## 지정 기준 원문 (건강검진기본법 시행규칙 [시행 2026.10.30.] [보건복지부령 제1206호])
- 출처 [근거]: https://www.law.go.kr/법령/건강검진기본법시행규칙 (헤드리스 브라우저), 별표 1 PDF https://www.law.go.kr/LSW/flDownload.do?flSeq=171019225 , 별표 2 PDF https://www.law.go.kr/LSW/flDownload.do?flSeq=171019231 (열람 2026-11-17)
- 제4조①: 위암·대장암·간암·폐암검진기관은 **"일반검진기관으로 지정받거나 지정받으려는 검진기관만"** 지정할 수 있다. → 위·대장암만 따로 신청할 수 없다.
- 제5조: 지정신청서 + 인력·시설·장비 현황, 인력 자격·채용 증명, (해당 시) 방사선 장치 검사성적서 등을 **건보공단**에 제출 → 공단 7일 안에 검토 → **구청장** 3일 안에 지정서 발급.

### 별표 1 일반검진기관 (개정 2019.9.27.)
| 구분 | 기준 | 의원 예외 |
|---|---|---|
| 인력 | 의사(일일 검진 25명당 1명), 간호사(간호조무사 포함) 1명 이상, 임상병리사 1명 이상, 방사선사 1명 이상 | 내원검진만 하고 일일 평균 검진 15명 미만이면 **임상병리사·방사선사 없어도 됨** |
| 시설 | 진찰실, 탈의실, 검진대기실, 임상검사 시설, 방사선촬영실 | 검체검사 위탁 시 임상검사 시설 면제(비고 2). 의료법 제39조 **장비 공동이용** 시 탈의실·방사선촬영실 면제(비고 3) |
| 장비 | 신장·체중계, 혈압계, 시력표, 청력계, 원심분리기, 혈액학검사기, 혈액화학분석기, 방사선직접촬영장치 | 위탁 시 혈액 장비 면제(비고 2). 공동이용 시 X선 장치 면제(비고 3) |
| 기타 | 고시 건강검진을 하려는 의사는 교육 이수(비고 1) | |

### 별표 2 암검진기관 (개정 2025.12.31.) — 내과 관련
| 암 | 신청자격 | 시설·장비 |
|---|---|---|
| 위암 | 일반검진기관 | 내시경실, 회복실, 위내시경 (조영검사 시 위장조영기·방사선사) |
| 대장암 | 일반검진기관 | 내시경실, 회복실, 대장내시경 (분변잠혈 장비 항목은 2025.12.31. 삭제) |
| 간암 | 일반검진기관 | 초음파영상진단기(식약처 시험기준 적합) |
- 비고 1: 일반검진기관이 신청하면 이 표의 인력기준(방사선사 제외)을 적용하지 않는다.

## 웰빙내과에 대입 [추론]
- 공개 등록 장비는 초음파뿐(2026.9. 심평원 파일, F4 노트). X선 장치가 없으면 **장비 공동이용(의료법 제39조) + 검체 위탁**으로 일반검진기관 요건을 맞출 수 있다(비고 2·3). 내원검진만, 일일 평균 15명 미만이면 임상병리사·방사선사도 필요 없다.
- 일반검진기관이 되면 위암·대장암(내시경 보유 시)과 간암(초음파 보유)을 함께 신청할 수 있다.
- 공동원장 인력 신고가 공개 자료에 1명으로 나오는 문제는 검진기관 신청서의 인력 현황과도 맞아야 한다.

## 선생님이 1분 안에 확인하는 법
- 건강iN(hi.nhis.or.kr) → 건강검진 → 검진기관 찾기에서 일산서구 검색.
- 요양기관정보마당(공단 기관 포털) 로그인 → 건강검진기관 메뉴.
- 건보공단 1577-1000 또는 고양일산지사.
