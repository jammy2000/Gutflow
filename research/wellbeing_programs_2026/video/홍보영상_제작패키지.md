## 1. 공통 규격

| 항목 | 값 |
|---|---|
| 화면 | 1920×1080, 30fps, H.264 mp4, 소리 트랙 없음 |
| 길이 | 58~62초. 마지막 1초가 첫 장면으로 겹쳐 바뀌어 무한 반복 |
| 구성 | ① 기전 15초 → ② 효과·인체모형 글로우 15초 → ③ 프로그램 구성 20초 → ④ 주의 문구 + 로고 8~10초 |
| 자막 | 나눔스퀘어라운드 800, 1080p 기준 64px(작게 보이는 TV는 72px), 흰 글자 + 반투명 어두운 띠(검정 55%), 화면 아래 안전영역(하단 10%) 위, 한 줄 16자 안팎·최대 2줄, 한 자막 최소 2.8초(읽는 속도 초당 6~7자), 들어올 때 0.2초 부드럽게 |
| 화면 글자 | 자막 + 프로그램 구성 카드 + 로고만(작아지는 내과의사 4장 "기본은 자막만" 규칙의 예외: 홍보영상이라 구성 카드 허용) |
| 몸 표현 | EP01 사람 아이콘(`flatbody.py`) 기본, 장기 강조는 MASK 하이라이트(나머지 어둡게 + 대상만 자기 색 은은한 글로우, `anim_util` MASK · `sh3_compose.highlight`) |
| 배경 | 해부 모형 장면 = 밝은 스튜디오(`bg_zones.bg_studio`), 몸속 = EP01 자두~와인빛 또는 EP02 플럼(선생님 선택) |
| 색 | 작아지는 내과의사 6장 색표 그대로. 호르몬 신호 = 라일락 #B5A3DA 알갱이 + 퍼지는 고리, 지방 = 레몬 #F4E08E, 근육 = 근육층 #7A3C38 계열 |
| 금지 | 장기·세포 의인화, 약·주사 펜·약병, 가격, 전후 비교, 숫자 큰 글씨 |
| 속도 | 3~4초마다 새 사건(카메라 컷·대상 등장·글로우·확대 원). 5초 넘게 새 사건 없는 구도 없음 |
| 반복 | 마지막 로고 → 0.8초 겹쳐 바뀜 → 첫 프레임(사람 아이콘 실루엣)과 같은 구도로 끝냄 |

**끝 카드**: 위에 프로그램 이름 한 줄(나눔스퀘어라운드 800, 56px, 흰색) → 아래 웰빙내과 W 로고(#195C3B, 환자앱 저장소의 로고와 같은 것) + "웰빙내과의원" + 주소 한 줄(일산서구 중앙로 1426). 전화번호는 선생님 결정.

## 6. 블렌더 작업 지시 (선생님 PC 세션용)

1. 장면 틀: `sh45_anim.py`(SHOT 정의) + `sh45_compose.py`(배경·자막·강조) 템플릿을 복사해 `promo_obesity.py` · `promo_aging.py` · `promo_fatigue.py` · `promo_meno.py`.
2. 몸: `flatbody.py` 사람 아이콘. 장기 위치는 아이콘 몸통 안에 단순 덩어리(뇌·갑상선·위·췌장·간·장·난소·뼈·근육 띠). 3D 몸 모형은 근육·뼈 장면에서만.
3. 강조: `anim_util` MASK(`MASK`, `MASK_T`) → 대상만 자기 색 글로우, 나머지 어둡게. 테두리 선 없음.
4. 호르몬 신호: 확정 부품 '호르몬 신호 B(알갱이 + 퍼지는 고리)' 재사용.
5. 구성 카드: 크림 바탕 둥근 네모 카드 + 3D 소품 하나 + 자막 문장. 사진 카드 몽타주(`sh1_cards.py`) 움직임을 응용해 톡 들어오고 옆으로 흐름. 카드 안 글자는 자막과 같은 글꼴.
6. 자막: `comp.py` 자막 기능, 규격은 1절. 시험 정지 화면(640×360)으로 TV 거리 가독성 확인 후 본 렌더.
7. 반복: 마지막 0.8초를 첫 프레임과 겹쳐 바뀜(합성 단계). 첫 프레임 = 마지막 로고 뒤 구도와 같은 사람 아이콘 실루엣.
8. 렌더: 이브이, 1920×1080, 30fps. 장면마다 시험 정지 화면 → 확인 → 본 렌더(작아지는 내과의사 1장 규칙).
9. 출력: `out/promo/웰빙_<obesity|healthyaging|fatigue|meno>_v1.mp4`, 무음. 폰 확인용 720p 따로. 파일 이름에도 "항노화" 쓰지 않음.
10. 카드 ④ 휴대폰 화면: Gutflow 저장소 `research/wellbeing_programs_2026/video/app_screens/app_<weight|aging|fatigue|meno>.png`(1170×2532, 가짜 자료로 그린 실제 앱 화면)를 휴대폰 3D 소품 화면 재질로. 위쪽 체크 부분만 보이게 자르고, 화면 안 글자는 읽히지 않아도 됨(자막이 설명). 홈 카드 화면 `app_home.png`는 마지막 카드 모임 장면에 선택.
