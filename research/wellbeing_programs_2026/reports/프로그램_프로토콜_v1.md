# 1. 네 프로그램 공통

## 1.1 급여·비급여 원칙

- 증상·징후·위험인자가 있어 진단·감별 목적이면 **급여 청구가 원칙**이다. 항목별 인정기준(대상·횟수)을 따른다 [추론·P3 A-0].
- 증상 없이 본인이 점검을 원하면 본인 희망 건강검진으로 **비급여**다. 같은 날 급여 진료와 섞을 때는 항목별 목적을 차트에 따로 적는다. 급여 대상을 임의로 비급여로 받으면 임의비급여다 [추론].
- 선별급여 항목(본인부담 80~90%): 비타민 간이검사(누490라 90%), TSH 간이검사(누325나 90%), 테스토스테론 질량분석(누374가 80%), LDL 분획(누264 80%) [근거·고시 제2026-200호].
- 비급여 가격은 고지하고, 고지 금액을 넘겨 받지 않는다(의료법 제45조) [근거].

## 1.2 공통 측정

| 측정 | 방법 | 기준 |
|---|---|---|
| 체성분 | 인바디(BIA) | 근육량지수 남 <7.0, 여 <5.7 kg/m²는 근감소 의심(단독 판정 금지) [근거·AWGS 2019, 10.1016/j.jamda.2019.12.012] |
| 근력·기능 | 악력, 5회 의자 일어서기, 6m 보행속도 | 악력 남 <28, 여 <18 kg / 의자 ≥12초 / 보행 <1.0 m/s [근거·AWGS 2019] |
| 우울·불안 선별 | PHQ-9, GAD-7 | 앱에 넣어도 됨(허가 불요) [추론·P3] |
| 노쇠 | K-FRAIL, SARC-F | K-FRAIL 3~5 노쇠, SARC-F ≥4 [근거·P3] |

수면 척도(PSQI·ISI·ESS·STOP-Bang)와 피로 척도(FSS), 폐경 척도(Greene)는 상업 사용 허가가 필요하다고 나온다(권리자 사이트 차단, [추론]). 앱에는 허가를 받기 전까지 넣지 않고, 종이 문진·진료 중 사용으로 둔다.

## 1.3 하지 않을 것

- 검사: 모발 미네랄·중금속(NECA "근거 없음" 의결), 음식 IgG(EAACI·CSACI 반대), 타액 코르티솔 일주기("부신피로"), 킬레이터 유발 소변 중금속, 텔로미어·후성유전 나이 단독, 유기산, NAD+ 혈중농도 패널 [근거·P2·P3].
- 처치: 무허가 NAD+ 수액, 킬레이션, 줄기세포·엑소좀 주사, 펩타이드, 항노화 목적 메트포르민·라파마이신.
- 광고·표현: 약 이름·주사 펜, 효과 보장, 전후 비교, 후기, "노화 역전", 가격 할인 이벤트(분야 3 보고서, 영상 패키지 0절).

## 1.4 앱(웰빙내과 상담앱·환자앱) 연동 원칙

- 기록·검사 결과: 상담앱 → 환자앱 사본(`patient_report/v1`)으로 보여 준다.
- 환자가 적는 체크(보충제·수면·피로 점수·운동): 환자앱 쪽에만 저장한다(10.29. 희망 로드맵과 같은 방식).
- 앱으로 하는 의사 상담은 2026.12.24.부터 비대면진료다. 처방은 대면으로 한다(특히 비만치료제는 비대면 처방 원칙 금지안) [근거·P1].
- 건강정보는 별도 동의를 받는다(개인정보보호법 제23조) [근거·P1].

# 2. 비만 진료 프로그램

**대상**: BMI 30 이상, 또는 동반질환이 있는 BMI 27 이상 성인(약물치료 허가 기준) [근거·위고비·마운자로 허가사항]. 그 밖은 생활 처방만.
**제외·주의**: 임신·수유, 갑상선 수질암·MEN2 병력, 췌장염 병력, 심한 위장관 질환. 급성 시력저하 시 중단 안내(식약처 2026.11.10. 안전성 정보, 내용은 보도 기준 [추론]).

| 단계 | 내용 |
|---|---|
| 초진(30분) | 문진(기존 상담앱 초진 문진), 인바디, 혈압, 악력·보행속도(50세 이상), 혈액검사, 치료 계획 |
| 혈액검사(급여 원칙) | 공복혈당·HbA1c, 지질, AST·ALT·GGT·혈소판(FIB-4), 크레아티닌·eGFR, 소변. 조건부: TSH, UACR, 요산 |
| 약물 | 허가 범위 안에서 대면 처방. 감량 후 유지는 최대용량 유지 또는 5 mg 감량 유지 중 선택(SURMOUNT-MAINTAIN: 112주 -21.9% / -16.6% / 위약 -9.9%, 10.1016/S0140-6736(26)00656-2) [근거] |
| 근육 보존 | 빠진 체중의 25~39%가 제지방(분야 3) → 단백질 1.0~1.2 g/kg/일, 주 2~3회 근력운동, 3개월마다 인바디·악력 [근거·추론] |
| 추적 | 월 1회 대면(5~10분), 3개월마다 인바디·악력, 6개월마다 혈액 |
| 앱 기록 | 체중(주 1회), 투약일·용량, 부작용 체크, 단백질·운동 체크 |
| 연결 | 고혈압·당뇨 → 만성질환관리, 40세 이상 위내시경 검진, 45세 이상 대장내시경 |

# 3. 건강노화 관리 프로그램 (원안: 항노화 클리닉)

**대상**: 50세 이상, 또는 근감소·대사 위험이 걱정되는 성인.
**목표**: 근육과 기능을 지키고, 대사·심혈관 위험을 조기에 찾는다. "노화를 되돌린다"고 하지 않는다.

| 단계 | 내용 |
|---|---|
| 초진(30~40분) | 인바디, 악력·5회 의자 일어서기·6m 보행, K-FRAIL·SARC-F, PHQ-9, 혈압, 혈액검사, 결과 상담 |
| 혈액검사 필수 | CBC, 공복혈당·HbA1c, 지질 4종, **Lp(a) 평생 1회**(D2620, 의원 평균 약 1.1만 원), AST·ALT·GGT·혈소판(FIB-4), 크레아티닌·eGFR, 소변 [근거·P3] |
| 혈액검사 조건부 | ApoB(TG↑·당뇨·비만), hs-CRP(중간위험), 시스타틴C(노쇠·저근육), UACR, 25(OH)D(골다공증·근감소·낙상), TSH, 요산, 페리틴, B12(메트포르민·PPI·채식) |
| 운동·영양 처방 | 주 2~3회 근력운동 + 유산소, 단백질 충분히. 근거: 운동 대형 RCT LIFE(10.1001/jama.2014.5616) [근거] |
| 보충제 권고(선택) | **크레아틴 5 g/일 + 근력운동**: 폐경 후 여성 RCT 메타분석에서 제지방 +0.37 kg, 다리 근력 +7.5 kg, 근력운동 없이 저용량은 효과 없음(10.1080/15502783.2026.2668435) [근거]. 신장질환자는 피함 [추론]. **오메가3**: 고중성지방혈증일 때만. 일반인 심혈관·암 예방 효과는 VITAL에서 음성(10.1056/NEJMoa1809944) [근거]. **비타민D**: 결핍·골다공증 위험일 때만 |
| 주사(선택) | 나이아신(브이트리주): 허가 효능(B3 결핍 등) 범위 설명. 홍조 부작용 안내. 효과 표현 금지 |
| 추적 | 6개월마다 인바디·악력·보행, 1년마다 혈액 |
| 앱 기록 | 근력운동 횟수, 단백질 체크, 걸음 수(선택), 6개월 재측정 알림, 결과 추세 |

# 4. 피로 원인 검사 프로그램 (원안: 만성피로 클리닉)

**대상**: 4주 이상 지속되는 피로.
**목표**: 원인을 찾아 치료하거나 배제한다. 원인 없는 피로는 수면·생활 관리.
**위험 신호(바로 정밀 평가·의뢰)**: 체중 감소, 발열·야간 발한, 림프절 비대, 흉통·호흡곤란, 신경학적 이상, 자살 사고(PHQ-9 9번).

| 단계 | 내용 |
|---|---|
| 초진(30분) | 피로·수면·기분 문진(PHQ-9·GAD-7, 수면 습관), 복용약 확인, 인바디, 혈압, 혈액검사 |
| 혈액검사 필수(급여 원칙) | CBC, ESR 또는 CRP, 공복혈당 또는 HbA1c, 전해질·칼슘, 크레아티닌·eGFR, 간기능(AST·ALT·ALP·GGT·알부민), TSH, 소변, **페리틴(가임기 여성)** [근거·P3, NICE NG206] |
| 조건부 | CK(근육통·스타틴), B12·엽산, 25(OH)D, 아침 코르티솔(부신기능저하 의심 징후), 셀리악, HIV·간염(위험요인), 수면무호흡 검사 의뢰(코골이·주간졸림) |
| HRV(선택, 비급여) | 개인 추세 관찰용. 결과를 진단·효과 판정에 쓰지 않음 |
| 처치 | 원인 치료(철결핍·갑상선·혈당·우울 등). 55세 이상 불면증이면 서카딘 단기 처방 검토. 영양수액은 선택, 효과 표현 없이 |
| 수면 환경 개선 | 기상 시각 고정, 침실 빛·온도·소음, 카페인·음주 시각, 낮잠 30분 이내 — 앱 체크리스트로 |
| 추적 | 4~6주 뒤 결과 상담, 3개월 재평가 |
| 앱 기록 | 피로 점수(0~10), 수면 시각, 수면 습관 체크, PHQ-9 재검(3개월) |

# 5. 갱년기(폐경기) 진료 프로그램

**대상**: 여성 40~60세 갱년기 증상. 남성은 증상 있는 경우 별도 평가.

## 5.1 여성

| 단계 | 내용 |
|---|---|
| 진단 | **45세 이상 전형 증상이면 FSH·E2 없이 증상으로 진단.** FSH는 40~45세 월경 변화 동반·40세 미만에서만(급여, LH 불인정) [근거·P1·P3] |
| 초진(30분) | 증상 문진(MRS는 상업 사용 확인 전까지 종이로), PHQ-9, 인바디, 혈압, 혈액검사 |
| 혈액·영상 | 지질·HbA1c/공복혈당(호르몬요법 고려자 필수), TSH(겹치는 증상), 간기능(경구 호르몬요법), CBC(출혈), **유방촬영 최근 결과 확인**, 골밀도(65세 이상 또는 위험인자) |
| 치료 | 호르몬요법: 경구제는 허가 범위 내 급여, 경피 겔은 비급여. 적응증·금기 평가 후. 비호르몬 치료 상담. 멜스몬주(허가 효능 "갱년기 장애 증상의 개선", 주 3회 2주 총 6회, 비급여, 투여 후 1년 헌혈 금지) |
| 보충제 권고 | 칼슘·비타민D는 골다공증 위험에 따라. 크레아틴 + 근력운동(위 3절 근거) |
| 추적 | 3개월 증상 재평가, 1년 유방촬영·지질 |
